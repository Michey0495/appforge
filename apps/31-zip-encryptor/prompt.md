# ZIP暗号化デスクトップアプリ 生成プロンプト

フォルダをドラッグ&ドロップするとパスワード付きZIPに固めるWin/Macデスクトップアプリを作ってください。

## 機能要件
- フォルダ・ファイルのドラッグ&ドロップ
- AES-256暗号化（伝統的ZipCryptoは使わない）
- パスワード強度メーター（リアルタイム）
- パスワード自動生成（CSPRNG、紛らわしい文字除外）
- 出力先フォルダ指定
- 複数フォルダの並列バッチ処理
- 監査ログ（CSVローカル保存）

## 技術スタック
- Tauri + React（推奨）または Electron + Node.js
- 暗号化: 7-Zip CLI を同梱してサブプロセス起動
- パスワード生成: crypto.randomBytes

## デザインルール
- 白背景、ネイビーアクセント（#2c52a4）
- ドロップゾーンは点線枠
- 強度バーは同系色濃淡（赤緑信号機色は使わない）
- 絵文字は使用しない
