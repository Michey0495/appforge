# ファイル一括リネーマー 生成プロンプト

フォルダ内のファイル名を一括変更するWin/Macデスクトップアプリを作ってください。

## 機能要件
- フォルダドロップで対象ファイル一覧
- プレビュー表示（変更前→変更後）
- 正規表現での検索・置換
- 連番採番（zero-padding桁数指定）
- 日付プレースホルダ {yyyy}/{mm}/{dd}/{exif:DateTimeOriginal}
- 拡張子の大文字小文字統一
- Undoでロールバック
- 衝突検出と自動回避

## 技術スタック
- Tauri + React（推奨）
- Rust側: walkdir, regex, image-rs
- 画像EXIF: exifr または rexif

## デザインルール
- 白背景、ネイビーアクセント
- プレビュー表は等幅フォント
- 危険操作は確認ダイアログ
- 絵文字は使用しない
